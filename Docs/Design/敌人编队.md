# 敌人编队

一局依次打四段。每段从两个关卡中选一个，每个关卡有三波固定敌人。开战后按第 1 波、第 2 波、第 3 波的顺序出怪。同一关重打时沿用相同的编队。

第 1 波在开战时入场。增援倒计时归零或场上敌人清空时，触发下一波。指定排的空位够整波入场时才刷出增援。同排写了多个敌人时，按书写顺序从前到后占空位。

## 两个关卡各考什么

| 段 | 左侧关卡 | 右侧关卡 |
| --- | --- | --- |
| 1 | 雪球拖慢行动，扫射考验分排 | 先打小鹅，最后处理企鹅团的连击 |
| 2 | 处理会越打越强的敌人，以及辣女巫受击时给全队的辣椒 | 处理反击和远射雪球，后两波会给雪吞吞创造加攻机会 |
| 3 | 山胡桃挡在快快前面，快快在后方给全队加攻 | 大黏黏受击给玩家黏黏水果，卡牌被摧毁时粘粘加攻 |
| 4 | 大雪怪施加雪球并带雪球抗性，和雪吞吞分列两排 | 先处理受击发辣椒和摧毁加攻，最后应对大脚怪的扫射 |

敌人数据取自 [卡牌设计原稿.xlsx](卡牌设计原稿.xlsx) 的「Sheet1」B26:C36。

雪卷卷按反击单位处理，被单位攻击且存活时用当前攻击力反击。雪球会阻止反击。麻可可、小莫科和山胡桃的「获得」按行动后生效。粘粘在单位阵亡或垃圾牌被摧毁时加攻。
