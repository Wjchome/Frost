# 六个主题关卡与敌人编队

当前远征只打三战，每段从两个关卡中选择一个，共六个可选关卡、八条完整路线。第一战的两个关卡各两波，第二、三战的四个关卡各三波。未来终局大关计划四波，本轮不制作，也不把旧首领关作为第三战。

每波固定两个基础怪（普通中等身材，或3生命的脆弱辅助），搭配两个或三个特色怪。末波在这一组合上另加一只关卡精英，形成4～6个敌人的一波。精英全关只出场一次，且只在末波。相同特色怪可以重复出场，让玩家先学会一种威胁，再处理数量和组合压力。

第1波开战入场。倒计时归零或敌阵清空时尝试增援；两排都能完整容纳下一波时才入场，暂时放不下就等待空位，不会漏刷、挤掉旧怪或刷到错误行。同排按下表书写顺序从前到后部署。首战间隔6拍，后两战5拍。

## 配置与备用内容

当前使用28种敌人，全部有实际出场。原稿「卡牌 · Cards」是数值来源；「敌人 · Enemies」展示当前投放、六关编队及备用名单；「敌人配合 · Combos」记录十组联动与公式数值示例。关卡波次和选路由 Config/Encounters 与 ExpeditionConfig 读取。

大雪怪、欧巴熊、雪卷卷、电荷爬虫、冰冠巨兽、铸炉暴君、引爆锤手共7种旧敌人保留资产与表格数据，当前不进入关卡、图鉴或GM。霜桥关口和白幕堡垒保留资产但退出远征选路。图鉴与GM只展示当前六关实际投放的敌人，按有效编队自动筛选；敌人不进入玩家招募和道具奖励。

攻击前生命转攻击与攻击后成长共用同一份能力配置。雪虫虫每次实际攻击前读取实时生命，增加本场攻击，可叠加；墨水停用，冻结或没有目标时不触发。治疗提高后续可增长的数值，造成伤害则降低它；已有攻击成长不会因失去治疗来源而撤销。卡面、悬停、回合预览与实际结算都读取同一份当前单位数据。

本轮为重新设计后的第一版数值，自动检查覆盖规则、编队和完整路线；四个部族的实玩难度仍以试玩反馈继续调整。
