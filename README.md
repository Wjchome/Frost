# 霜线信使

用 Unity 6 制作的雪地卡牌连战。每次远征打三战，每段二选一，共六个主题关卡；首战两波，后两战各三波。未来终局关暂未接入。

## 启动

- 用 Unity 6000.0.85f2 打开工程和 `Assets/Scenes/Dispatch.unity`，点 Play。
- Windows 试玩版位于 `Builds/Windows/FrostlineDispatch.exe`。移动试玩版时保留该目录内的所有文件。
- 编辑器中可通过 Windows 构建配置出包，也可在批处理模式调用 `Frostline.DispatchBuild.BuildWindows`。
- 标题页点击「开始远征」进入选队。标题页和战斗右上角可以开关音效。

## 卡牌配置

- 在 Unity 的 Project 面板打开 `Assets/Resources/Config`，选中资产后在 Inspector 编辑。
- `Cards` 存放卡牌与敌人的引用资产，名称须与原稿中的卡牌 ID 一致，关卡通过这些资产指定出场单位。
- 游戏的数值与能力统一读取 `Docs/Design/卡牌设计原稿.xlsx` 的「卡牌 · Cards」，资产名称作为卡牌 ID 用于关卡引用。「敌人 · Enemies」集中展示当前投放的28种敌人、六关波次及7种备用敌人；「敌人配合 · Combos」记录十组联动；编队说明见 `Docs/Design/敌人编队.md`。
- `Factions` 配置各部族的领袖池、起始牌组、出发补给、专属随从池和专属道具。起始牌按列表顺序入牌堆，重复引用同一资产即可配置多张。
- `ExpeditionConfig` 配置可选部族、开局伙伴、通用随从池和各阶段关卡。勾选阶段的随从招募后，该阶段的战后选牌会提供两张部族专属随从与一张通用随从。
- `Encounters` 配置每关的背景、增援间隔和各波敌人。每波可选 1 至 6 个单位，逐个指定首选行，1 是上排，2 是下排。如果棋盘空位不足，增援会等待空位。关卡资产还包含战后候选和挂坠奖励。
- 场景的 `Dispatch` 对象通过 `UIDocument` 加载 UXML 和 USS。手牌、场上单位和牌组一览中的卡面由 `DispatchBoard.cs` 按数据生成，插画通过名字从 `Assets/Resources/CardArt` 读取。

## 连战流程

- 先选雪人、垃圾人、召唤者或地形改造者，再选领袖；部族初始伙伴随队免费部署。卡名、效果与暂定规则见 `Docs/Design/卡牌落地说明.md`。
- 按 C 打开卡牌图鉴，可按部族筛选并查看单位、道具的数值和效果。
- 依次选择风蚀雪谷（雪球）或沉钟驿站（士气连击）、白脊菌园（生命成长）或红炭营地（辣椒）、晶壳工段（格挡护壳）或孢雾哨塔（中毒）。每波2个基础怪加2～3个特色怪，末波另加1精英；详见 `Docs/Design/敌人编队.md`。
- 首战胜利后可以三选一招募随从。第二战胜利后，从两张部族道具和一张通用道具中选一张。选中的牌会在下一战开局抽到。主角、随从和开局伙伴都可以装备挂坠并带入余下战斗。
- 暖石挂坠使最大生命 +2，调律挂坠使触发效果数值 +1，疾行扣使最大倒计时 −1，最低为 1。重试本战保留卡组、挂坠和永久成长。重新出发时按配置初始化新卡组。

## 局内规则

- 每场开局可以按任意顺序免费部署所选主角和随从，再抽六张开局手牌。主角倒下会结束战斗，随从可在正式开战后撤回。
- 双方各有两排，每排三格。把手牌拖到合法目标，或先选牌再点目标。每次出牌推进一回合，敌方先结算倒计时。
- 倒计时归零时立刻行动，随后恢复到最大倒计时。用道具直接把倒计时降至零时，马上行动，并在本回合的常规结算中照常倒计时。
- 雪球阻止倒计时减少。受雪球影响而跳过本回合倒计时的单位在回合末失去一层雪球。抗雪球的单位最多持有一层。
- 卡面上方显示生命条和攻击力，底部中央的金色沙漏显示行动倒计时。生命条下方的图标显示状态与层数。悬停单位查看效果名和触发数值。狂热单位每次行动连续攻击，下一击会按当时的站位重新选目标。
- 普通攻击打同排最前的对手，远射打最后一位，横扫打同排所有对手，无法瞄准从目标排随机选一位。同排没有对手时转到另一排。
- 援护单位倒计时归零时，把技能用在同排最靠前的其他友军身上，同排落单时无法援护。墨水停用援护技能。
- 悬停手牌可见可用目标。悬停场上单位可看它的攻击目标和技能，紫色表示随机候选。选择手牌后指向棋盘会高亮即将受到效果的对象。
- 选中或拖动一张牌，指向合法目标可预览出牌后的生命、防护、击倒和增援。按 Tab 可常驻显示下一拍的行动顺序。预览按先结算牌效、再结算双方倒计时的顺序计算。
- 拖牌时绿色边框标记可落点，红色边框标记无法出牌的位置。有效格边缘会吸附，放到无效位置会把牌送回手中。
- 顶栏显示下一波的敌人和增援倒计时。倒计时归零或提前清空敌阵时，增援会在当拍末入场。开启预览可在棋盘上看到预计的入场位置。
- 渡崖人部署时获得 2 点护壳，岚哨长每击倒一名敌人恢复 2 点生命，崖脊卫命中施加 1 层雪球。卡面直接显示触发条件和数值。
- 拖动或点击己方单位换位。可把队员拖到「收回队员」撤回。撤回清除临时状态并恢复最多 5 点生命，再把队员放入弃牌堆。换位和撤回均免费。
- 换牌铃冷却归零后可以免费换牌。提前敲铃会推进一回合。空格敲铃，Esc 或鼠标右键取消选择。
- 按 B 查看队伍和牌组。战斗中也可点抽牌堆或弃牌堆查看其中的牌，点卡牌可查看数值、能力和挂坠。Esc 关闭查看界面。

## 叠加效果

悬停道具可查看规则，棋盘卡面显示当前层数。裂霜刃对带雪球的目标多造成 3 点伤害，回火钳对带过载的目标多造成 3 点伤害。

| 道具 | 效果 |
| --- | --- |
| 辛辣油 | 给一名友方加 3 层辣椒。每层使攻击 +1，打完整次攻击后清除。狂热的每一击都能吃到加成。 |
| 电荷罐 | 给一名敌方加 4 层过载。层数达到存活目标的当前生命时引爆，对自身和同排队友造成等量伤害。伤害降低生命后也会检查，能引发连锁爆炸。 |
| 染墨瓶 | 给一名敌方加 4 层墨水。墨水停用触发能力，每个结算回合结束减少 1 层。 |
| 校准尺 | 使一名友方的触发能力数值在本场战斗内 +1。多次使用可以叠加，撤回后保留。岚哨长的击倒回血会从 2 变为 3。 |
| 应急盾 | 给一名友方加 2 层格挡。每层抵消一次伤害，格挡先于护壳。 |
| 钝化粉 | 给一名敌方加 3 层虚弱。每层使攻击 −1，最低为 0，打完整次攻击后清除。 |
| 倒刺护腕 | 给一名友方加 2 层反伤。承受一次有伤害的单位攻击后，若仍存活，对攻击者造成等同层数的伤害，再减少 1 层。 |
| 余烬燃剂 | 给一名敌方加 3 层灼烧。回合末受到等同层数的伤害，再减少 1 层。 |
| 磨刃石 | 巡路牌组的出发补给。指定一名友方单位，使该张牌在本次远征中永久增加 1 点基础攻击。 |
| 路标钩 | 把一名敌人拉到另一排的第一个空位。可拆散援护组合，也可把危险的敌人拉到伤害集中的一排。 |
| 裂冰针 | 给一名敌方加 3 层易伤。下次未被格挡的伤害增加等同层数的伤害，再清空易伤。 |
| 缝雪绷带 | 给一名友方永久增加 2 点最大生命，并回复 2 点生命。成长会带到后续战斗。 |
| 铆头锤 | 造成 2 点伤害，目标有护壳时额外造成 3 点。 |

凿冰师命中施加 2 层过载。裂谷巨像横扫命中时给存活的目标施加 2 层墨水。

巡灯哨手行动时给同排前方友军加护壳，灯阵技师是玩家可招募的援护牌。穿隙猎手远射施加易伤，门庭机兵会对整排施加易伤。赤炉巨臂连续攻击并附加灼烧，炉边护卫可带入玩家卡组。

巡路队可在出发补给中选择倒刺护腕，过载队可选择余烬燃剂。灼烧受击能力在被单位攻击并存活时给攻击者叠加灼烧。旧敌人资产可保留为备用，仅当前有效编队的敌人进入图鉴与 GM。这项受击能力会被墨水停用。灼烧在增援入场前结算，也能压低生命并引爆过载。

规则参考《雪居之地》公开的 [皇冠](https://wildfrostwiki.com/Crowns)、[倒计时](https://wildfrostwiki.com/Counter)、[雪球](https://wildfrostwiki.com/Snow)、[攻击](https://wildfrostwiki.com/Attack) 和 [队员](https://wildfrostwiki.com/Companions) 说明。试玩使用本工程的雪谷场景、角色与卡面素材。角色卡面由 `Tools/generate_card_faces.py` 合成，道具插画由 `Tools/generate_equipment_faces.py` 生成。字体授权见 `Assets/Resources/Fonts/OFL.txt`。

标题画面、关卡背景和音效可通过 `Tools/generate_presentation.py` 重新生成。
