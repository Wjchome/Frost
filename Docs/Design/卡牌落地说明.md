# 卡牌设计

设计以同目录 [卡牌设计原稿.xlsx](卡牌设计原稿.xlsx) 的「Sheet1」为准。原始截图见 [卡牌原稿.png](卡牌原稿.png)。Unity 配置位于 `Assets/Resources/Config`。

每局先选雪人或垃圾人，再选领袖和一名开局伙伴。两个部族各有六张初始牌。通用牌出现在战后奖励中。

| 部族 | 六张初始牌（按抽取顺序） |
| --- | --- |
| 雪人 | 雪球、巨大雪球、法杖、大武器、乱打武器、大雪球 |
| 垃圾人 | 冰淇淋、桶、留声机、火焰弹、垃圾炸弹、垃圾 |

图鉴在标题页、选关界面和战斗上方。按 C 打开，点雪人、垃圾人或通用标签，再选卡查看数值和效果。

## 新增卡牌

**永久垃圾**属于垃圾人战后道具池。打到任意友军身上即装备。从下一回合开始，本场每回合向手牌生成 1 张垃圾。每份装备各自生效。免费换牌时回合计数保持原值。

## 暂定规则

| 原稿写法 | 本次实现 |
| --- | --- |
| 初始 1 个伙伴、6 张卡 | 每部族从表中六名伙伴任选一名。该部族 C 列的道具组成初始牌组，垃圾人再从 D 列补一张垃圾。领袖沿用现有配置。 |
| 提高随机队友 1 点属性 | 从其他在场友军中随机选一名，本场增加 1 攻击或 1 最大生命。增加最大生命时回复等量生命。 |
| 爱垃圾者使垃圾增加同等数量的攻击 | 手中每张垃圾增加等同于爱垃圾者当前攻击力的伤害。 |
| 火焰弹增加狂热并施加虚弱 | 同一名友军同时获得 1 狂热和 4 虚弱。 |
| 伤害法杖伤害 4、计数 −3 | 对同一名敌人造成 4 伤害并减少其倒计时 3。 |
| 粉刀让前排友军获得造成数量的血量 | 优先治疗与目标同排的最前方友军，按实际扣除的生命回复。 |
| 护盾和护甲 | 两者按现有护壳规则结算。 |
| 消耗 | 用过后从本场移出。要求垃圾的道具会摧毁相应张数的手中垃圾。 |
| 受击能力 | 单位须在受击后存活。保护者在友军单位击杀时触发。 |
| 扫射 | 用于法杖和桶时作用于选择的一整排，用于大武器时赋予所选友军横扫。 |

Excel 的「Sheet1」C18 为空。截图里的冰骰子见原稿截图。
