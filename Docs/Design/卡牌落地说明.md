# 卡牌设计

卡牌数据统一放在同目录 [卡牌设计原稿.xlsx](卡牌设计原稿.xlsx)。「Sheet1」是手写设计稿，「部族」表和「卡牌」表是游戏实际读取的数据。Unity 编辑器直接读取这个文件，保存后进入 Play Mode 或重新开始远征时生效；打包时会自动把它嵌入游戏。编辑器菜单 **Frostline → 校验卡牌配置表** 可以检查列名、数值、卡牌 ID 和奖励归属，**Frostline → 打开卡牌设计原稿** 可以直接打开文件。

「卡牌」表一张牌一行，按雪人、垃圾人、召唤者、地形改造者、通用、敌人分组，每个部族有 10 名伙伴；未投放的旧敌人可保留行，适配阶段标记为备用，当前图鉴和 GM 根据有效关卡自动筛掉它们。「类型」为部署的行是单位，读取生命到额外数值；其他类型是道具，读取伤害到增伤数值，消耗、横扫、使用次数、连续回血等规则填在同一行的规则列。关卡引用通过卡牌 ID 匹配表格，「部族」表按卡名引用。新增卡可通过「新增投放」列加入图鉴或战后奖励。卡牌资产的名称保留为旧引用的 ID。现有卡牌各自使用独立插画。新版资源位于 `Assets/Resources/CardArt/Expedition/Redrawn`，由「插画路径」列指定。效果和触发条件可以从「填写说明 · Guide」复制中英对照值，例如「雪球 / Snow」，也可以直接填英文代码 `Snow`。

「部署」在上场时结算一次，已经施加的效果有自己的持续规则。来源撤回或死亡后，已施加的效果继续按原规则结算。「在场上时」持续提供加成，来源撤回、死亡或被墨水封住时移除它提供的加成。「每个回合受伤状态触发」在回合末检查当前生命是否低于上限。该触发仍可供后续卡牌使用。新增「攻击前 / BeforeAttack」表示每段实际攻击造成伤害前触发；雪虫虫的「生命转攻击 / HealthAttackUp」按此时生命增加本场攻击，能力数值填倍率1。

「反击」是单位的独立开关。填 1 且倒计时填 0 表示仅反击，例如雪卷卷。填 1 且倒计时大于 0 表示同时拥有普通攻击和反击，例如格挡爱好者。反击按当前攻击力结算并保留当前倒计时。

卡面使用青铜蓝绿伙伴框、铜红敌人框和黄铜道具框。名称放在顶部，生命、攻击和倒计时显示当前值。状态图标单独显示层数，超过四种时以「+N」收起其余状态，悬停卡牌时，完整列表会逐项显示状态名称、当前数值和规则，多项状态可以滚动查看。战场底部提示行已移除，格子效果和出牌说明也由悬停面板展示。迷雾、永久垃圾、临时攻击、延迟伤害和持续恢复均有独立显示；卡面与状态详情读取同一份当前单位数据。卡框、规则纸面和图标放在 `Assets/Resources/CardArt/Interface`。

「卡牌」表的「适配阶段」记录伙伴适合的远征阶段，可填前期、前中期、中期、中后期、后期或全期。这一列只作设计参考，游戏不读取。

图鉴在标题页、选关界面和战斗上方。按 C 打开，点雪人、垃圾人、召唤者、地形改造者或通用标签，再选卡查看数值和效果。图鉴和 GM 的选卡列表先显示伙伴，再显示道具。

战斗左下方可以查看抽牌堆、弃牌堆和消耗堆，牌组一览也有对应标签页。带「消耗」的道具、复制白卡，以及使用次数耗尽的道具进入消耗堆，本场不再洗回抽牌堆。预览不会改变消耗堆，重试或新战斗会重新按远征牌组建立牌堆。

战场每排从靠敌阵的 1 号位依次站满。部署到己方的单位牌可以插进已有单位的位置，同排单位依次后移。同排满时，最后一名移到同阵营另一排最靠前的空位。拖拽时可先看挤位结果，两排都满时无法部署。面具召唤和敌方部署使用该排最靠前的空位。已上场的单位可以交换位置。前方出现空位时，同排单位按原顺序前移。战斗中在当前攻击及其连击、反击结算完后补位。

开发版本的战斗界面提供 **GM** 菜单，当前有「加手牌」和「加敌人伙伴」。加手牌保留原有选卡方式。加敌人伙伴只列出单位，可按部族筛选，添加到敌方任一排最靠前的空位。添加不会推进回合。GM 添加的敌人按普通敌人行动并计入通关条件，阵亡不会成为玩家的卡牌。所有修改仅影响本场战斗。功能入口统一由 `DispatchBoard.GameMasterTools` 列表生成，后续可继续加入其他调试功能。

当前共有六个主题关卡，每次远征三战，各段二选一。第一战两波，后两战各三波；每波2个基础怪与2～3个特色怪，末波另加1精英。主题为雪球、士气连击、生命成长、辣椒、格挡护壳、中毒。未来终局四波大关暂不制作。28种敌人实际投放，7种旧敌人保留数据但退出图鉴、GM与有效编队。数值仍以原稿「卡牌 · Cards」为准，原稿的敌人页和配合页已同步职责、编队、成长说明与拆解方法。详细波次见 [敌人编队.md](敌人编队.md)。

雪虫虫9 / 0 / 4在每次攻击前按当前生命增加攻击（本场叠加）；麻可可5 / 0 / 1在每次攻击后攻击+1。脆弱辅助多为3生命。格挡、护壳、治疗、辣椒、攻击施毒与格子毒都沿用现有规则。卡面与预览显示实时数值，辅助离场不清除已施加的治疗、辣椒或攻击施毒。

## 地形改造者

开始新远征时可选「地形改造者」，从四名试玩领袖随机抽出的三名中选一名。领袖和起始牌组为试玩配置。10 名伙伴加入部族招募池，可在图鉴查看，也可以用 GM 加入手牌测试。10 名伙伴和 19 张道具都配置在「卡牌」表。道具可在图鉴查看，可由 GM 加入手牌，也会作为部族战后道具奖励。19 张道具各有一张原创插画，手牌、图鉴和 GM 共用「卡牌」表里的插画配置。

格子效果跟随站位。伙伴换位、撤回、阵亡或补位时，格子的固定攻击、临时攻击和未结算的状态保持原位。临时攻击与中毒都在每回合结束减 1，施加当回合也会衰减，空格照常衰减。回合末，所有格子毒减少 1 层；有单位占格时，按衰减前层数对其造成伤害，空格只减少层数。格子毒不再一次性转为单位中毒。格子虚弱与格子辣椒只修正当前占格单位的攻击，不转移为单位状态。单位实际出手才消耗，整次狂热连击共用出手时的层数；倒计时未到、被雪球阻止、无目标或换位时都留在原格。攻击中新增的格子虚弱或辣椒保留给下一次攻击。地形爱好者放大正负效果，墨水会停用这项能力。

站桩每场首次部署时铺地。爆破手在每次铺地或叠层时成长一次，横扫同一次攻击给多个格子铺毒也只触发一次。下放转移自身的攻击，吸收者保留吸来的固定攻击至本场结束，吸来的临时攻击仍会衰减。放手一搏在脚下格子留下 5 点临时攻击和 5 层毒。吸毒者在行动前移除脚下 1 层格子毒并恢复 1 点生命，剩余格子毒在回合末正常结算。

地形道具可以选择任意格子，含双方空格。格子狂热由占格单位获得，换位时留在原格。毒满天下同时让双方单位中毒，并给双方所有格子铺毒。精神错乱会与另一随机格子交换全部效果。吸收地形使目标本场攻击 +3、脚下格子固定攻击 −1：普通单位原地净增 2 攻，换位后保留单位的 +3，−1 留在原格。以身饲毒立即将自身全部中毒转到脚下格子，使用当回合即可生效，也可以被地形吸收者当回合吸收。

施加反伤提供按当前攻击一半向下取整的反伤，随临时攻击等修正变化，与固定反伤合并结算。它不再赋予反击攻击方式，也不触发普通攻击的附带效果。原生反击仍按全攻及原攻击方式结算。反伤卡面只写数值或比例，通用触发条件放在悬停说明中。毒爆读取目标当前的中毒层数并造成伤害，之后照常结算回合末的中毒。毒攻追加的中毒可叠加并受墨水限制，持续到本场离场。刮骨疗伤按实际移除的毒层数扣血。格子换攻击将攻击和毒的代价铺在目标脚下。各卡的具体数值和使用次数见原稿。

## 新增卡牌

**永久垃圾**是垃圾人的战后道具奖励。可附着在任意在场的友军或敌军身上，每份让该单位在场时于回合开始向玩家手牌生成 1 张垃圾。多份效果可叠加。撤回时暂停，重新部署同一张卡后继续。阵亡后失去。免费换牌不推进回合。

### 飞书截图新增

| 奖励池 | 新增内容 |
| --- | --- |
| 雪人道具 | 明灯、平衡杆、强力、急攻、分散火力 |
| 垃圾人道具 | 冰甲、狂歌、破烂打击、变废为宝、精英垃圾、狂暴垃圾 |
| 通用道具 | 格挡群、大火球、毒药瓶、迟缓钟 |
| 通用随从 | 格挡爱好者 |

**分散火力**：独立随机选择友军 3 次，每次使该友军本场攻击 +1，允许重复选中。因此可以分成 3、2+1 或 1+1+1，领袖也能被选中。卡面、预览与实际结算均按原稿的「数值 1、次数 3」读取。

两张未命名的倒计时道具暂用「急攻」和「迟缓钟」。平衡杆的计数 +1 按最大倒计时 +1 结算。最大倒计时提高后，下次倒计时重置取新上限。迟缓钟可以对一名敌人使用，单张牌在本场用满三次后消耗。狂歌只能吞噬非领袖友军，其余在场友军随机一名获得等同于被吞噬者当前狂热次数的狂热。垃圾翻倍按复制每张手中的垃圾结算，变废为宝每摧毁一张垃圾就抽一张牌。每张变废为宝每场可用两次，第二次用完进入消耗堆。

格挡群随机为一名友军加 2 格挡、为一名敌军加 1 格挡。格挡爱好者的普通攻击和反击覆盖两排全体敌军，每次攻击后给全体敌军各施加 1 层雪球。格挡爱好者被单位攻击后存活，或场上任一单位消耗格挡时，会独立反击一次。自身挡住一次攻击时按一次反击结算。中毒在回合末造成等同于层数的伤害，先消耗格挡，再消耗护壳，最后扣生命，中毒随后减少 1 层，可被净化。格子毒也按这个伤害顺序结算。

### Excel 补充

垃圾存储者为 5 生命、6 攻击、5 倒计时。**睡觉**给所选单位的当前倒计时加 1，从本回合结束起依次回复 3、6、9 点生命。**腐化刀**让所选单位在本场增加 4 点当前和最大生命，同时获得 1 层腐化。腐化在未被格挡的伤害命中时将伤害翻倍并消耗 1 层，护壳在翻倍后扣除。

直接选择场上单位的普通道具，目标在原稿中填「任意单位 / Either」。腐化刀、雪球、墨水汁等可用于双方，战场会标出可选目标。横扫同排的道具作用于所选阵营的该排。献祭、召唤、复制友军、同归于尽及指定阵营的全体或随机效果按各自规则选目标。

原稿里没写触发时机的能力按「攻击后」处理。非召唤伙伴和雪人、垃圾人的伙伴规则相同，阵亡后本场不再回来。

**召唤**：在场单位不能主动召回。单位阵亡（包括被献祭）后回到弃牌堆，恢复满生命，永久成长保留。**部署在敌方**：只能放进敌方空位，成为敌方单位，所以它的「友军」「同排队友」都是敌人，有攻击时会攻击我方；它计入通关条件，吸吸、炸弹人等敌方单位必须全部击倒才能获胜。**献祭**：自己的非领袖单位被自己打死就算献祭，所有部族通用，只是雪人和垃圾人没有相关联动。包括被大嘴、狂歌吞噬，被面具头骨、过载队员献祭，被自己的卡牌（例如垃圾、致命增强的延迟伤害）或自己单位的攻击打死（例如同归者打自己、中了迷雾的队友误伤）。灼烧、中毒、过载爆炸和脆弱者自身扣血致死不算。骨头刀击倒敌人也算一次。每次献祭触发一次「友军被献祭」。攻击或倒计时填 -1 表示没有；没有倒计时也不反击的单位不会主动行动，卡面攻击显示为「—」。

**迷雾**：每层让单位的下一次攻击改打自己的友军，同排优先，不打自己；攻击后减少 1 层，没有其他友军时这次攻击落空。召唤出的单位阵亡后作为卡牌回到弃牌堆，所以面具每用一次，本场牌组就多一张对应伙伴。复制品按原单位当前的永久攻击和最大生命生成，本场加成不复制。原稿没写是否消耗的道具都按可重复使用处理。

**延迟伤害**：致命增强在使用的下一回合结束时结算，护壳和格挡照常生效，单位详情和状态栏显示待结算的伤害。如果单位的倒计时在这两个回合内归零，它会先用加成后的攻击出手。**同归于尽**和**过载放电**都在过载改完后才检查引爆：同归于尽按（原过载 + 1）× 2 计算；过载放电先结算伤害，再把过载减半。友军因同归于尽过载引爆而阵亡不算献祭。刺甲和过载放电的名字是暂定的，可在原稿里改。
