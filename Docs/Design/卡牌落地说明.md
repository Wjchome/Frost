# 卡牌设计

设计以同目录 [卡牌设计原稿.xlsx](卡牌设计原稿.xlsx) 的「Sheet1」为准。Unity 的生效数据在 `Assets/Resources/Config/CardWorkbook.xlsx`。保存修改后，进入 Play Mode 或重新开始远征时会重新读取。编辑器菜单 **Frostline → 校验卡牌配置表** 可以检查列名、数值、卡牌 ID 和奖励归属。

「单位」和「道具」各用一行定义一张卡。「附加规则」按同一个 ID 配置消耗、横扫、使用次数或连续回血。现有初始牌组、奖励池和关卡引用通过卡牌 ID 匹配表格。新增卡可通过「新增投放」列加入图鉴或战后奖励。卡牌资产的名称保留为旧引用的 ID。效果和触发条件可以从「填写说明 · Guide」复制中英对照值，例如「雪球 / Snow」，也可以直接填英文代码 `Snow`。

「在场上时」在每次上场时结算一次。撤回后重新部署算再次上场。「每个回合受伤状态触发」在回合末检查当前生命是否低于上限。雪努努每次满足条件，本场攻击 +2。

每局先选雪人或垃圾人，再选领袖和一名开局伙伴。两个部族各有六张初始牌。通用牌出现在战后奖励中。

| 部族 | 六张初始牌（按抽取顺序） |
| --- | --- |
| 雪人 | 雪球、巨大雪球、法杖、大武器、乱打武器、大雪球 |
| 垃圾人 | 冰淇淋、桶、留声机、火焰弹、垃圾炸弹、永久垃圾 |

图鉴在标题页、选关界面和战斗上方。按 C 打开，点雪人、垃圾人或通用标签，再选卡查看数值和效果。

## 新增卡牌

**永久垃圾**是垃圾人的第六张起始牌。打到任意友军身上即装备。从下一回合开始，本场每回合向手牌生成 1 张垃圾。每份装备各自生效。免费换牌时回合计数保持原值。

### 飞书截图新增

| 奖励池 | 新增内容 |
| --- | --- |
| 雪人道具 | 明灯、平衡杆、强力、急攻、分散火力 |
| 垃圾人道具 | 冰甲、狂歌、破烂打击、变废为宝、精英垃圾、狂暴垃圾 |
| 通用道具 | 格挡群、大火球、毒药瓶、迟缓钟 |
| 通用随从 | 格挡爱好者 |

两张未命名的倒计时道具暂用「急攻」和「迟缓钟」。平衡杆的计数 +1 按最大倒计时 +1 结算。最大倒计时提高后，下次倒计时重置取新上限。迟缓钟可以对一名敌人使用，单张牌在本场用满三次后消耗。狂歌只能吞噬非领袖友军，其余在场友军随机一名获得等同于被吞噬者当前狂热次数的狂热。垃圾翻倍按复制每张手中的垃圾结算，变废为宝按每销毁一张垃圾抽一张牌结算。

格挡群随机为一名友军加 2 格挡、为一名敌军加 1 格挡。格挡爱好者的普通攻击覆盖两排全体敌军。行动后和自身消耗格挡时，给全体敌军施加 1 层雪球。触发格挡时还会反击攻击者。中毒在回合末扣除等同于层数的生命并减少 1 层，可被净化。新增卡暂用工程内已有插画。

### Excel 补充

以原稿 `Sheet1` 的手填区域为准。垃圾存储者为 5 生命、6 攻击、5 倒计时。**睡觉**给友军的当前倒计时加 1，从本回合结束起依次回复 3、6、9 点生命。**腐化刀**让所选友军在本场增加 4 点当前和最大生命，同时获得 1 层腐化。腐化在未被格挡的伤害命中时将伤害翻倍并消耗 1 层，护壳在翻倍后扣除。

| 奖励池 | 本轮新增 |
| --- | --- |
| 雪人随从 | 糖妈妈、肉盾狗、松鼠、过回合者 |
| 垃圾人随从 | 等我启动、同归者、集中者、脆弱者 |
| 通用随从 | 小蜜蜂、自虚弱者 |
| 雪人道具 | 腐化刀 |
| 垃圾人道具 | 多重攻击 |
| 通用道具 | 饱和打击、睡觉 |

需要确认的落地口径如下。

- 等我启动每次行动后成长，糖妈妈每次行动后提高其他友军的当前及最大生命。饱和打击和多重攻击作用于在场友军，本场有效。
- 肉盾狗比较双方当前生命。同归者和松鼠每次狂热攻击均单独触发。自虚弱者行动后给同排所有友军施加虚弱，包括自己。
- 集中者按同排每位其他友军各自能给出的数值吸收，以实际吸收的数值强化自身。友军至少保留 1 点最大生命。
- 过回合者正常行动后让友军额外走 1 拍。敌军行动、增援、换牌铃和回合末效果仍只结算一次。额外拍中的行动不会再触发额外拍。
- 原稿另有木疙瘩和吊坠设计，属于后续独立规则。

## 暂定规则

| 原稿写法 | 本次实现 |
| --- | --- |
| 初始 1 个伙伴、6 张卡 | 从部族开局伙伴中选择一名。初始牌组按 C 列配置，领袖沿用现有配置。 |
| 提高随机队友 1 点属性 | 从其他在场友军中随机选一名，本场增加 1 攻击或 1 最大生命。增加最大生命时回复等量生命。 |
| 爱垃圾者使垃圾增加同等数量的攻击 | 手中每张垃圾增加等同于爱垃圾者当前攻击力的伤害。 |
| 火焰弹增加狂热并施加虚弱 | 同一名友军同时获得 1 狂热和 4 虚弱。 |
| 伤害法杖伤害 4、计数 −3 | 对同一名敌人造成 4 伤害并减少其倒计时 3。 |
| 粉刀让前排友军获得造成数量的血量 | 优先治疗与目标同排的最前方友军，按实际扣除的生命回复。 |
| 护盾和护甲 | 两者按现有护壳规则结算。 |
| 消耗 | 用过后从本场移出。要求垃圾的道具会摧毁相应张数的手中垃圾。 |
| 受击能力 | 单位须在受击后存活。保护者在友军单位击杀时触发。 |
| 扫射 | 用于法杖和桶时作用于选择的一整排，用于大武器时赋予所选友军横扫。 |
