# 霜线信使

用 Unity 6 制作的雪地卡牌连战。每次出发选择一个低级关卡和一个高级关卡。

## 启动

- 用 Unity 6000.0.85f2 打开工程和 `Assets/Scenes/Dispatch.unity`，点 Play。
- Windows 试玩版位于 `Builds/Windows/FrostlineDispatch.exe`。移动试玩版时保留该目录内的所有文件。
- 编辑器中可通过 Windows 构建配置出包，也可在批处理模式调用 `Frostline.DispatchBuild.BuildWindows`。

## 连战流程

- 出发时从岚哨长的巡路牌组、铆桥队长的过载牌组、霜径领航员的雪球牌组中选一组，再从寻路幼兽、巡灯蜂与雪绒盾卫中选一名随从。
- 低级关卡从风蚀雪谷、沉钟驿站中二选一。获胜后从冰沟向导、暖炉芯、消磁罩中选一张加入卡组，下一战开局抽到。
- 风蚀雪谷掉落暖石挂坠，使队员最大生命 +2。沉钟驿站掉落调律挂坠，使队员的触发效果数值 +1。选一张符合条件的队员牌装备，挂坠随牌保留。
- 高级关卡从霜桥关口、白脊风口中二选一。霜桥守机横扫附加过载，裂牙首领连续攻击并施加虚弱。重试本战保留卡组和挂坠，重新出发回到低级选关。

## 局内规则

- 每场开局可以按任意顺序免费部署所选主角和随从，再抽六张开局手牌。主角倒下会结束战斗，随从可在正式开战后撤回。
- 双方各有两排，每排三格。把手牌拖到合法目标，或先选牌再点目标。每次出牌推进一回合，敌方先结算倒计时。
- 倒计时归零时立刻行动，随后恢复到最大倒计时。用道具直接把倒计时降至零时，马上行动，并在本回合的常规结算中照常倒计时。
- 雪球阻止倒计时减少。受雪球影响而跳过本回合倒计时的单位在回合末失去一层雪球。抗雪球的单位最多持有一层。
- 卡面上方显示生命条和攻击力，底部中央的金色沙漏显示行动倒计时。生命条下方的图标显示状态与层数。悬停单位查看效果名和触发数值。狂热单位每次行动连续攻击，下一击会按当时的站位重新选目标。
- 普通攻击打同排最前的对手，远射打最后一位，横扫打同排所有对手，无法瞄准从目标排随机选一位。同排没有对手时转到另一排。
- 悬停手牌可见可用目标。悬停场上单位可看它的攻击目标和技能，紫色表示随机候选。选择手牌后指向棋盘会高亮即将受到效果的对象。
- 点「行动顺序」或按 Tab，可预览下一拍。选牌后指向合法目标，预览会按先结算牌效、再结算双方倒计时的顺序更新。
- 顶栏显示下一波的敌人和增援倒计时。倒计时归零或提前清空敌阵时，增援会在当拍末入场。开启预览可在棋盘上看到预计的入场位置。
- 渡崖人部署时获得 2 点护壳，岚哨长每击倒一名敌人恢复 2 点生命，崖脊卫命中施加 1 层雪球。卡面直接显示触发条件和数值。
- 拖动或点击己方单位换位。可把队员拖到「收回队员」撤回。撤回清除临时状态并恢复最多 5 点生命，再把队员放入弃牌堆。换位和撤回均免费。
- 换牌铃冷却归零后可以免费换牌。提前敲铃会推进一回合。空格敲铃，Esc 或鼠标右键取消选择。

## 叠加效果

巡路牌组第一次换牌可拿到六张效果道具。悬停道具可查看规则，棋盘卡面显示当前层数。

| 道具 | 效果 |
| --- | --- |
| 辛辣油 | 给一名友方加 3 层辣椒。每层使攻击 +1，打完整次攻击后清除。狂热的每一击都能吃到加成。 |
| 电荷罐 | 给一名敌方加 4 层过载。层数达到存活目标的当前生命时引爆，对自身和同排队友造成等量伤害。伤害降低生命后也会检查，能引发连锁爆炸。 |
| 染墨瓶 | 给一名敌方加 3 层墨水。墨水停用触发能力，每个结算回合结束减少 1 层。 |
| 校准尺 | 使一名友方的触发能力数值在本场战斗内 +1。多次使用可以叠加，撤回后保留。岚哨长的击倒回血会从 2 变为 3。 |
| 应急盾 | 给一名友方加 2 层格挡。每层抵消一次伤害，格挡先于护壳。 |
| 钝化粉 | 给一名敌方加 3 层虚弱。每层使攻击 −1，最低为 0，打完整次攻击后清除。 |

凿冰师命中施加 2 层过载。裂谷巨像横扫命中时给存活的目标施加 2 层墨水。

规则参考《雪居之地》公开的 [皇冠](https://wildfrostwiki.com/Crowns)、[倒计时](https://wildfrostwiki.com/Counter)、[雪球](https://wildfrostwiki.com/Snow)、[攻击](https://wildfrostwiki.com/Attack) 和 [队员](https://wildfrostwiki.com/Companions) 说明。试玩使用本工程的雪谷场景、角色与卡面素材。牌面由 `Tools/generate_card_faces.py` 合成本工程已有插画生成。字体授权见 `Assets/Resources/Fonts/OFL.txt`。
